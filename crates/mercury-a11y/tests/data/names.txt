# Accessible name and description cases for `names::apply` (through `compute`).
#
# One case per block, blocks separated by blank lines. Keys: `case` (identifier), `html` (one line,
# parsed by `TestDom::from_html`), `target` (id of the element under test, default `t`), `name`
# (expected label, `<none>` for no label), `desc` (expected description, `<none>` for none; left out
# when the case does not care), `note` (free text). Written from the Accessible Name and Description
# Computation 1.2 (steps 2A-2I), HTML-AAM section 4.2 and the Mercury decisions in the header of
# `src/names.rs`; a `note:` says where Chromium differs.
