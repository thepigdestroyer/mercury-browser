# The ARIA role names an author may write and the AccessKit role each one is exposed as.
#
# Written by hand from the W3C role tables (WAI-ARIA 1.2 section 5.4, the Digital Publishing module,
# the Graphics module) and from the names of AccessKit's `Role` (which follows Chromium's role list),
# as a second record beside the table in `src/roles.rs`: the test compares the two, so a typo in
# either one fails. One entry per line: `name => Role` (the `Debug` name of the AccessKit role).
#
# Where AccessKit has no role of its own, the entry says which role is used (see the header of
# `src/roles.rs`): subscript, superscript, none, presentation and generic are generic containers,
# directory is a list.
