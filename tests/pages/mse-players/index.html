MSE players

The three JavaScript players that the Media Source Extensions work must run, each on a generated 8 s stream (built from the fixtures of crates/mercury-mse-testkit by serve-tests, nothing is copied into the repository). Start the browser with MERCURY_DEV_MSE=1 and the server with scripts/serve-tests.sh; fetch the players once with scripts/dev/fetch-mse-tools.sh. Each page ends its title with "(done)" and shows PASS and FAIL lines; scripts/dev/mse-window-run.sh players runs the three and writes a report.

  • dash.js: DASH, /mse-dash/h264/manifest.mpd
  • Shaka Player: DASH, /mse-dash/h264/manifest.mpd and the WebM set /mse-dash/vp9/manifest.mpd
  • hls.js: HLS (fMP4), /mse-hls/h264/master.m3u8

By hand, the same streams can be opened in any other player: the manifests are the URLs above on the same server.
